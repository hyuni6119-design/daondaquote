# 골드TV 하루 작업 흐름

2026-09-22 에 실제로 한 번 끝까지 돌려보고 잰 시간입니다.
결과물은 **1시간 4분짜리 모음집 1편** + 곡당 영상 18편이었습니다.

---

## 전체 그림

```
① 가사 쓰기        6편          →  02-가사/*.md
② 수노에서 곡 뽑기  가사당 2곡+   →  D:\골드TV\<번호-제목>\*.mp3
③ 그림 2장 만들기   GPT          →  썸네일용 1, 재생화면용 1
④ 곡당 영상 만들기  ffmpeg       →  mp3 옆에 같은 이름 mp4
⑤ 모음집 이어붙이기 ffmpeg      →  _완성\완성.mp4  (2초, 다시 인코딩 안 함)
⑦ 제목·설명 짓기   도구         →  _완성\업로드정보.json
⑧ 썸네일 만들기    캡컷 Ctrl+S  →  _완성\썸네일.jpg
⑨ 유튜브 업로드    도구         →  황금 주파수 TV
```

---

## 단계별로 쓰는 것과 걸린 시간

| 단계 | 도구 | 걸린 시간 | 사람이 붙어야 하나 |
|---|---|---|---|
| ① 가사 6편 | 내가 씀 | 10분 | 아니오 (읽고 확인만) |
| ② 수노 곡 12~18개 | suno.com | 40~60분 | 조금 (생성 확인) |
| ③ 그림 2장 | `이미지만들기.py` | 3분 | 아니오 |
| ④ 곡당 영상 18편 | `노래영상만들기.py` | **18분** | 아니오 |
| ⑤ 모음집 이어붙이기 | `모음집이어붙이기.py` | **2초** | 아니오 |
| ⑥ 제목·설명 | `업로드정보만들기.py` | 1분 | 고르기만 |
| ⑦ 썸네일 | 캡컷 Ctrl+S | 5분 | 문구 정하기 |
| ⑧ 업로드 363MB | `업로드.py` | **4분** | 처음 한 번만 로그인 |

**합계 약 1시간 20분**. 그중 **사람이 실제로 붙어 있어야 하는 건 20~30분**
이고 나머지는 기다리는 시간입니다.

### 왜 캡컷으로 렌더하지 않나

처음에는 모음집을 캡컷에서 통째로 내보냈는데, 재어 보니 이렇습니다.

| | 캡컷이 통째로 렌더 | 곡당 만들고 이어붙이기 |
|---|---|---|
| 인코딩 | 5분 | **2초** |
| 파일 크기 | 3,094MB | **363MB** |
| 업로드 | 34분 | **4분** |
| 합계 | 39분 | **4분** |

이어붙이기는 `-c copy` 라 **다시 인코딩을 아예 하지 않습니다.** 그리고
정지 화면이라 곡당 영상은 0.8Mbps로도 깨끗한데 캡컷은 6.4Mbps로 뽑아서
파일이 8배 커집니다. 올리는 속도가 초당 1.5MB라 크기가 곧 시간입니다.

대신 황주 고정 문구(채널명·안내 문구·곡 제목)를 **곡당 영상 만들 때 미리
구워 넣습니다.** 나중에 얹으려면 전체를 다시 인코딩해야 해서 이점이
사라지기 때문입니다. 인트로 14초만 따로 만들어 맨 앞에 붙입니다.

GPU 인코딩(NVENC)도 재어 봤는데, RTX 3060 은 있지만 그래픽 드라이버가
낮아 이 ffmpeg 에서는 쓰지 못합니다. 어차피 이어붙이기가 더 빠릅니다.

## 명령 한 줄씩

```bash
# ③ 그림 (하루 2장)
python 도구\이미지만들기.py --용도 썸네일   "장면 설명" "D:\골드TV\_오늘이미지\썸네일.png"
python 도구\이미지만들기.py --용도 재생화면 "장면 설명" "D:\골드TV\_오늘이미지\영상용.png"

# ④ 곡당 영상 (황주 고정 문구까지 구워 넣습니다. 있는 건 건너뜀)
python 도구\노래영상만들기.py --배경 "D:\골드TV\_오늘이미지\영상용.png" --전체 "D:\골드TV"

# ⑤ 모음집 이어붙이기 (2초)
python 도구\모음집이어붙이기.py --배경 "D:\골드TV\_오늘이미지\영상용.png" --곡폴더 "D:\골드TV" --저장 "D:\골드TV\_완성\완성.mp4"

# ⑥ 제목·설명 (챕터는 ⑤가 남긴 수록곡.json 에서 자동으로 읽습니다)
python 도구\업로드정보만들기.py --저장 "D:\골드TV\_완성" --문구 "D:\골드TV\_완성\문구.json"

# ⑧ 업로드
python 도구\업로드.py "D:\골드TV\_완성"
```

⑦은 황주썸넬에서 그림·문구 바꾸고 **Ctrl+S** 로 저장합니다.
캡컷은 이제 **썸네일 만들 때만** 씁니다.

⑤가 `_완성\수록곡.json` 에 곡별 시작 시각을 적어 두고, ⑥이 그걸 읽어
챕터를 만듭니다. 캡컷 프로젝트는 만들지 않아도 됩니다. 인트로가 앞에 붙어
첫 곡이 0:00 이 아니면 `0:00 인사말` 줄을 자동으로 넣습니다(유튜브는 첫 줄이
0:00 이 아니면 챕터를 아예 안 만듭니다).

## 손이 꼭 가야 하는 세 군데

1. **수노 곡 생성** — 만들기 버튼이 여러 번 눌리면 한 가사에서 2곡보다 많이
   나옵니다. 오늘도 008이 6곡, 009가 4곡 나왔습니다.
2. **썸네일 문구** — 그날 제목에 맞춰 네 줄을 새로 씁니다.
3. **제목 고르기** — 후킹구를 이틀 연속 같은 걸 쓰지 않습니다.
