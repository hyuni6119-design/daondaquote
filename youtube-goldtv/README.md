# 골드TV 유튜브 작업 공간

유튜브 영상 제작 관련 작업물을 보관하는 폴더입니다.
불교 경전을 현대 가사로 옮겨 노래와 영상으로 만드는 롱폼 채널입니다.
같은 저장소에 있는 `index.html`(견적서 자동생성기)과는 별개이며, 서로 영향을 주지 않습니다.

## 폴더 구성

| 폴더 | 들어가는 것 |
|---|---|
| `00-채널정보.md` | 채널 주제, 타깃 시청자, 말투 등 기본 설정 |
| `01-기획/` | 영상별 기획안 (주제, 구성, 촬영 계획) |
| `02-가사/` | 곡별 수노 프롬프트(가사)와 영상 구성 |
| `03-업로드/` | 제목, 설명란, 해시태그, 썸네일 문구 |
| `04-자막/` | 자막 파일 (.srt) |
| `05-리서치/` | 트렌드 조사, 경쟁 채널 분석 |
| `콘텐츠-캘린더.md` | 업로드 일정과 진행 상황 한눈에 보기 |
| `수노-프롬프트-가이드.md` | Styles 기본값, 구조 태그, 후렴 설계 규칙 |
| `유명-경전구절-모음.md` | 가사에 쓸 수 있는 구절 목록 (1군/2군/금지) |
| `도구/` | 노래 생성·영상 편집·썸네일·업로드 자동화 스크립트 (윈도우) |

## 파일 이름 규칙

영상 하나당 같은 번호를 씁니다. 나중에 찾기 쉽습니다.

```
01-기획/001-어머니의-열가지-은혜.md
02-가사/001-어머니의-열가지-은혜.md
03-업로드/001-어머니의-열가지-은혜.md
04-자막/001-어머니의-열가지-은혜.srt
```

## 작업 요청하는 법

Claude에게 이렇게 말하면 됩니다.

- "2번 아이디어로 기획안 써줘"
- "그걸로 수노 프롬프트 써줘"
- "이 곡에 맞는 제목 10개랑 썸네일 문구 뽑아줘"
- "불교 노래 채널들 조사해줘"
- "영상 아이디어 더 뽑아줘"

결과물은 위 폴더에 자동으로 저장되고 커밋까지 됩니다.

## 자동화 도구

`도구/` 폴더에 곡 하나를 유튜브에 올리기까지의 전 과정을 자동화한 스크립트가 있습니다.

```
1-노래만들기.bat   수노 API로 노래 생성 → mp3 내려받기
2-영상만들기.bat   노래 + 영상 클립 + 자막 → 완성.mp4
3-썸네일만들기.bat 배경 사진 + 문구 → 썸네일.png
4-업로드.bat       유튜브에 제목·설명·태그·썸네일까지 한 번에
```

설치와 사용 순서는 **`도구/사용법.md`** 를 보세요.
캡컷 없이 명령 한 번으로 편집이 끝납니다.

**VS Code에 Claude Code를 설치하면 이 스크립트들을 Claude가 직접 실행합니다.**
말 한마디로 노래 생성부터 유튜브 업로드까지 처리됩니다.
→ **`도구/VS코드에서-작업하기.md`**

## 주의

작업물은 **커밋·푸시되어야** 영구 보관됩니다. 대화창만으로는 남지 않습니다.

API 키와 구글 인증 파일은 저장소에 올라가지 않도록 막아두었습니다 (`도구/.gitignore`).
