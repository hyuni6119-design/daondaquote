## ② 수노 사이트에서 8곡 (월 구독)

곡마다(`곡` 목록 8개) suno.com 「Create」 → Custom:
- **제목** = `제목`, **Styles** = `스타일`, **Lyrics** = `가사` (`[Style: …]` 줄은 이미 빠져 있음)
- 수노는 한 번에 2곡을 줍니다. **둘 중 하나만 씁니다** (8곡 = 서로 다른 가사 8개)
- 워크스페이스는 날짜+채널로 새로 만듭니다 (예: `1105bulsim`, `1104gold`)
- **이미 아는 함정** (작업기록.md 의 「수노」 절에 자세히):
  - 가사 칸은 Lexical 편집기 — `__lexicalEditor` 로 넣거나 클립보드+Ctrl+V. `insertText`·`\n` 은 한 줄로 뭉개짐
  - 「만들기(Create)」는 좌표 클릭이 안 먹음 → 포인터 이벤트로 누르기. **두 번 누르지 않기** (곡이 두 배로 생김)
  - 워크스페이스 목록은 빵부스러기의 「Workspaces」 글자를 눌러야 함 (이름 쪽 누르면 이름이 바뀜)
  - `/create` 로 새로 들어가면 Styles 칸이 기본값으로 돌아감 → 곡마다 다시 넣기
  - 내보내기를 한꺼번에 많이 걸면 밀림 → 8개씩
  - 파파고 번역 확장이 끼면 끄고 진행
- 다 받으면 각 mp3 를 `곡폴더\NN-제목\<제목>.mp3` 로 옮깁니다 (폴더마다 **mp3 1개**).
  ffprobe 로 길이를 재서 수노 목록과 맞는지 확인합니다 (엉뚱한 폴더로 들어가는 일이 있었음).
- `python 밤작업.py 상태 <id> 노래받음 "8곡"`

## ③ 영상 만들기 (효과합성 1바퀴 → 3바퀴)

```bash
python 효과합성.py --채널 <채널> --배경 "<폴더.배경>" --곡폴더 "<폴더.곡폴더>" --저장 "<폴더.완성>\1바퀴.mp4"
python 두번붙이기.py "<폴더.완성>\1바퀴.mp4" "<폴더.완성>\완성.mp4" "<폴더.완성>\수록곡.json" <규칙.loops>
```
- `<채널>` 은 `불심명언` / `황금주파수`. 1바퀴 33분짜리 약 10분 걸립니다.
- 완성 길이가 `규칙.min_minutes` 보다 짧으면 바퀴를 하나 늘려 다시 붙입니다 (100분 조금 넘는 건 괜찮음).
- `두번붙이기.py` 가 3바퀴 전부의 `수록곡.json` 을 남깁니다 (설명 챕터에 씀).
- `python 밤작업.py 상태 <id> 영상완성 "<길이>분"`

## ④ 사이트로 올리기 (서버가 유튜브에 일부 공개로)

```bash
python 밤작업.py 올리기 <id> "<폴더.완성>\완성.mp4" "<폴더.완성>\수록곡.json" "<썸네일 jpg>"
```
- 제목·설명·태그는 사이트 편 것을 그대로 씁니다. 설명의 🕐 수록곡(챕터)은 서버가 넣습니다.
- 끝나면 상태가 「올림」이 되고, 몇 분 안에 서버가 유튜브에 올려 사이트 「📌 내가 할 일」에 **검토** 로 뜹니다.
- 올리기까지 끝난 편의 큰 파일(1바퀴.mp4·완성.mp4)은 지우지 않습니다 (검토에서 다시 만들기가 나올 수 있음). 2주 지난 것만 정리.
