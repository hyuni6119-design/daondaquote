# 라이브 제품 태그 붙이기 (예약 작업이 이 순서대로 함)

유튜브 API로는 제품 태그를 못 붙여서, PC의 웨일(Claude in Chrome)이 스튜디오에서 붙입니다.
서버 브라우저는 구글 본인 인증(패스키만 됨) 때문에 못 씁니다 — 2026-10-26.

## 순서

1. 지금 켜진 라이브와 태그 여부를 서버에서 받습니다.
   ```bash
   ssh -i ~/.ssh/hetzner_live root@168.119.152.95 "cd /opt/live-manager && sudo -u livemgr node tools/tag-list.js"
   ```
   `tagged: false` 인 것만 합니다. 없으면 바로 끝냅니다 (아무것도 열지 않음).
2. 웨일에서 새 탭을 하나 만들고, 각 라이브의 `url` 로 갑니다
   (황금주파수 = `?authuser=1`, 불심명언 = authuser 없음 — 주소는 tag-list 가 만들어 줌).
   **이동하자마자(기다리지 말고) 먼저 이것부터 실행합니다** — 웨일의 다른 유튜브 확장이 스튜디오에
   자기 창(chrome-extension:// iframe)을 끼워 넣으면 그 뒤로 스크립트·클릭이 모두
   「Cannot access a chrome-extension:// URL of different extension」으로 막힙니다 (2026-10-27):
   ```js
   const kill = () => document.querySelectorAll('iframe[src^="chrome-extension://"], embed[src^="chrome-extension://"], object[data^="chrome-extension://"]').forEach(f => f.remove()); kill(); new MutationObserver(kill).observe(document.documentElement, {childList:true, subtree:true}); 'guard on'
   ```
   이미 막혔으면 그 탭을 닫고 새 탭으로 다시 이동해서 바로 위 코드부터 실행합니다.
3. 6초쯤 기다린 뒤 `도구\라이브제품태그.js` 내용을 그 탭에서 실행합니다.
   - 한 번에 45초를 넘기면 도구가 끊기므로, 오래 걸리면 두 번에 나눕니다:
     ① 제품 칸 펼치기 → 「제품 수정」 → 「태그」(+) 4개 ② 「완료」 → 페이지 「저장」
   - **저장했다고 바로 믿지 않습니다.** 같은 주소로 다시 이동(새로고침)해서 가드 코드를 다시 실행하고,
     `[aria-label*="태그된 제품"]` 가 「태그된 제품 4개」인지 확인한 뒤에만 적습니다
     (2026-10-27 저장 단계가 오류로 끊겼는데 적어 버려서 태그 없는 라이브가 생길 뻔함)
   - 확인되면 서버에 적습니다:
     ```bash
     ssh -i ~/.ssh/hetzner_live root@168.119.152.95 "cd /opt/live-manager && sudo -u livemgr node tools/tag-list.js done <영상번호>"
     ```
   - `실패` 면 적지 않습니다 (다음 예약 때 다시 함). 이유가 「본인 인증」이면 사장님께 알립니다.
4. 다 하면 만든 탭을 닫습니다.

## 붙이는 제품

「최근 태그된 제품」의 위 4개 (노래 영상에 넣던 것과 같음 · 채널마다 따로).
불심명언 = 불상 계열 4개.

## 걸리는 것

- 탭이 화면 앞에 있어야 제품 창이 열립니다
- 페이지를 옮길 때 「나가시겠습니까?」 창이 뜨면 탭이 멈춥니다 → 그 탭을 닫고 새 탭으로
- 라이브는 24시간이라, PC가 늦게 켜져도 그때 붙이면 됩니다. 3시간 넘게 안 붙으면 라이브 관리자 ‘내가 할 일’에 뜹니다
