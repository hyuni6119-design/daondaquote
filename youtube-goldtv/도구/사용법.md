# 도구 사용법 (윈도우)

곡 하나를 만들어 유튜브에 올리기까지, **버튼 네 번**이면 됩니다.

```
1-노래만들기.bat   →  수노에서 노래 받아오기
2-영상만들기.bat   →  노래 + 영상 합쳐서 mp4 만들기
3-썸네일만들기.bat →  썸네일 png 만들기
4-업로드.bat       →  유튜브에 제목·설명·태그·썸네일까지 올리기
```

---

## 처음 한 번만 하는 준비

### 1) 파이썬 설치

https://www.python.org/downloads/ 에서 내려받아 설치합니다.

> 설치 화면 맨 아래 **"Add python.exe to PATH"** 에 반드시 체크하세요.
> 이걸 빼먹으면 나중에 "python을 찾을 수 없습니다" 가 뜹니다.

### 2) 나머지 자동 설치

**`0-처음설치.bat`** 을 더블클릭합니다. 파이썬 꾸러미와 ffmpeg가 자동으로 깔립니다.
끝나면 창을 닫고, **명령 프롬프트를 새로 열어야** 설치한 것이 인식됩니다.

### 3) 수노 API 키 넣기

도구 폴더에 **`api키.json`** 파일을 만들고 이렇게 적습니다.

```json
{ "suno": "여기에_사장님_수노_API_키" }
```

> 이 파일은 `.gitignore` 에 등록돼 있어 저장소에 올라가지 않습니다.
> **API 키는 절대 다른 사람에게 보여주지 마세요.** 채팅창에도 붙여넣지 마시고요.

### 4) 유튜브 업로드 권한 받기 (4번 쓸 때만)

1. https://console.cloud.google.com 접속 → 새 프로젝트 만들기
2. **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용 설정**
3. **API 및 서비스 → OAuth 동의 화면** → 외부 → 앱 이름 아무거나 → 본인 이메일을 **테스트 사용자**로 추가
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID** → 유형은 **데스크톱 앱**
5. 만들어진 JSON을 내려받아 **`client_secret.json`** 이라는 이름으로 이 도구 폴더에 넣기

처음 `4-업로드.bat` 을 실행하면 브라우저가 열리며 로그인을 묻습니다. 한 번만 하면 됩니다.

## 곡 하나 만드는 순서

### 작업 폴더를 이렇게 만듭니다

```
C:\골드TV\001-비우니-채워지더라\
├── 곡정보.json        ← 1번 실행 전에 필요 (곡정보-예시.json 복사해서 수정)
├── 노래.mp3           ← 1번 실행하면 여기 생깁니다
├── 영상\              ← 사장님이 만든 영상/이미지를 넣는 곳
│   ├── 01.mp4
│   ├── 02.mp4
│   └── 03.png
├── 자막.srt           ← 선택. 있으면 화면에 자막이 구워집니다
├── 설정.json          ← 선택. 클립 길이 등을 바꿀 때만
├── 배경.jpg           ← 썸네일 배경 사진
├── 썸네일.json        ← 썸네일 문구
├── 업로드정보.json    ← 제목, 설명, 태그
├── 완성.mp4           ← 2번 실행하면 생깁니다
└── 썸네일.png         ← 3번 실행하면 생깁니다
```

`-예시.json` 파일들을 복사해서 `-예시` 를 떼고 쓰시면 됩니다.

### 실행하는 법

**bat 파일 위로 작업 폴더를 끌어다 놓으면** 바로 실행됩니다.
그냥 더블클릭하면 폴더 경로를 물어보는데, 그때 폴더를 창에 끌어다 놓고 엔터를 쳐도 됩니다.

## 각 도구가 하는 일

### 1-노래만들기

`곡정보.json` 의 가사와 스타일을 수노 API로 보내고, 완성된 mp3를 내려받습니다.
후보가 여러 개 오면 `노래-후보2.mp3` 처럼 함께 저장됩니다.
들어보시고 가장 좋은 것을 **`노래.mp3`** 로 이름을 바꿔두세요.

> 수노 API는 제공하는 곳마다 주소와 응답 형식이 조금씩 다릅니다.
> 처음 실행에서 오류가 나면 **화면에 찍힌 내용을 그대로 저에게 보여주세요.** 맞게 고쳐드리겠습니다.

### 2-영상만들기

`영상\` 폴더의 클립들을 **이름순으로 8초씩** 배치하고, 노래 길이만큼 반복해서 채웁니다.
- 어떤 화면 비율이든 1920×1080으로 잘라 맞춥니다
- 정지 이미지는 아주 천천히 확대해서 영상처럼 보이게 합니다
- 장면이 바뀔 때 부드럽게 넘어갑니다
- `자막.srt` 가 있으면 화면에 구워 넣습니다
- 끝에서 화면과 소리가 함께 잦아듭니다

12분짜리는 만드는 데 몇 분 걸립니다. 창을 닫지 마세요.

클립이 머무는 시간을 바꾸려면 `설정.json` 의 `클립길이` 숫자를 고치세요.

### 3-썸네일만들기

`배경.jpg` 위에 `썸네일.json` 의 문구를 얹어 1280×720 PNG를 만듭니다.
두 줄은 자동으로 같은 크기로 맞춰지고, 글자가 묻히지 않게 배경 아래쪽을 어둡게 깔아줍니다.
배경 사진이 없으면 금빛 그러데이션으로 대신 만듭니다.

### 4-업로드

`완성.mp4` 를 `업로드정보.json` 의 제목·설명·태그와 함께 올리고, `썸네일.png` 까지 적용합니다.

- `"공개범위"` : `private`(비공개) / `unlisted`(일부공개) / `public`(공개)
- `"예약시간"` : `"2026-09-20T21:00:00+09:00"` 처럼 적으면 그 시각에 자동 공개됩니다

> **처음에는 반드시 `private` 로 올려서** 유튜브에서 직접 확인한 뒤 공개로 바꾸세요.

끝나면 `업로드결과.txt` 에 영상 주소가 저장됩니다.

## 자주 나는 오류

| 메시지 | 해결 |
|---|---|
| `python을 찾을 수 없습니다` | 파이썬 설치 때 "Add python.exe to PATH" 체크를 안 한 것입니다. 다시 설치하세요 |
| `ffmpeg을 찾을 수 없습니다` | `0-처음설치.bat` 실행 후 **명령 프롬프트를 새로 열어야** 합니다 |
| `Pillow가 필요합니다` | `pip install pillow` |
| 자막 글자가 네모로 깨짐 | `설정.json` 의 `자막_글꼴` 을 `Malgun Gothic` 으로 두세요 |
| 썸네일 적용 실패 | 유튜브 채널 인증(전화번호)이 안 되어 있으면 맞춤 썸네일을 못 씁니다 |
| 업로드 할당량 초과 | 유튜브 API는 하루 업로드 횟수에 제한이 있습니다. 하루 기다리세요 |
