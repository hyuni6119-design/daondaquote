# VS Code에서 작업하기 (권장)

지금 이 대화는 **클라우드 서버**에서 돌아갑니다. 그래서 사장님 컴퓨터의 파일을 만지거나
수노에 접속할 수가 없습니다.

**VS Code에 Claude Code를 설치하면 그 제약이 사라집니다.**
Claude가 사장님 컴퓨터에서 직접 명령을 실행하기 때문입니다.

---

## 무엇이 달라지나

| 단계 | 지금 (클라우드) | VS Code에서 |
|---|---|---|
| 가사 쓰기 | ✅ | ✅ |
| 수노로 노래 생성·다운로드 | ❌ 접속 차단 | ✅ **Claude가 직접 실행** |
| mp4 편집·합치기 | ❌ | ✅ **Claude가 직접 실행** |
| 썸네일 만들기 | ⚠️ 파일 전달 필요 | ✅ **Claude가 직접 저장** |
| 유튜브 업로드 | ❌ | ✅ **Claude가 직접 실행** |
| 이미지 생성 | ❌ | ❌ (여전히 불가) |

VS Code에서는 **"1번 곡 만들어서 유튜브에 비공개로 올려줘"** 한마디면
Claude가 네 단계를 알아서 순서대로 실행합니다.

**여전히 사장님이 하셔야 하는 것**
- 이미지 생성 (미드저니, 챗지피티 등) 과 영상화
- 유튜브 첫 로그인 한 번 (브라우저 창이 뜹니다)

---

## 설치 순서

### 1) VS Code 설치
https://code.visualstudio.com 에서 내려받아 설치합니다.

### 2) Claude Code 확장 설치
VS Code를 열고 왼쪽 네모 네 개 아이콘(확장) 클릭 → **`Claude Code`** 검색 → 설치

설치 후 `Ctrl + Esc` 를 누르면 Claude 창이 열립니다. 처음에 로그인을 한 번 합니다.

### 3) 파이썬 설치
https://www.python.org/downloads/

> 설치 화면 맨 아래 **"Add python.exe to PATH"** 체크 필수

### 4) 저장소 내려받기

VS Code에서 `Ctrl + Shift + P` → `Git: Clone` 입력 → 아래 주소 붙여넣기

```
https://github.com/hyuni6119-design/daondaquote.git
```

내려받은 뒤 왼쪽 아래 브랜치 이름을 눌러 **`claude/fervent-mendel-124aee`** 로 바꿉니다.

### 5) 나머지 설치

Claude 창에 이렇게 말하면 됩니다.

```
youtube-goldtv/도구/0-처음설치.bat 실행해줘
```

## 준비 파일 두 개

### api키.json
`youtube-goldtv/도구/` 안에 만듭니다.

```json
{ "suno": "여기에_수노_API_키" }
```

### client_secret.json (유튜브 업로드용)
구글 클라우드 콘솔에서 받아 같은 폴더에 넣습니다. 순서는 `사용법.md` 참고.

> **이 두 파일은 `.gitignore` 로 막아뒀습니다.** 저장소에 올라가지 않습니다.
> 채팅창에도 키를 붙여넣지 마세요. 파일에만 넣으시면 Claude가 알아서 읽습니다.

## 작업 폴더 만들기

```
C:\골드TV\001-비우니-채워지더라\
└── 영상\        ← 사장님이 만든 영상/이미지만 여기 넣어두시면 됩니다
```

나머지 파일(`곡정보.json`, `업로드정보.json`, `썸네일.json`)은
Claude에게 만들어 달라고 하면 채워서 넣어줍니다.

---

## 실제로 이렇게 말하면 됩니다

```
C:\골드TV\001-비우니-채워지더라 에 곡정보.json 만들어줘.
가사는 youtube-goldtv/02-가사/001-비우니-채워지더라.md 에 있는 걸로.
```

```
수노 돌려서 노래 받아줘
```

```
영상 폴더에 클립 넣어놨어. mp4 만들어줘
```

```
썸네일 만들고 유튜브에 비공개로 올려줘
```

명령을 실행할 때마다 **"허용하시겠습니까?"** 창이 뜹니다.
매번 누르기 번거로우면 `/config` 에서 자동 허용으로 바꿀 수 있습니다.

**둘 다 쓰시면 됩니다.**

- **기획·가사·제목 쓰기** → 지금 이 대화 (휴대폰에서도 됩니다)
