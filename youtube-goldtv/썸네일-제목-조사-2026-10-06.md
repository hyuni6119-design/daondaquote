# 잘 되는 영상은 어떻게 쓰는가 — 조사 2026-10-06

사장님이 「유튜브를 검색해서 잘나가는 영상이 어떻게 제목을 구성하고
썸네일 문구를 했는지 보고 아이디어를 얻어라」 하셔서 조사했습니다.

두 군데를 봤습니다.
1. **우리 황금주파수 TV 공개 539편 중 조회수 위에서 20편** (API로 정확한 수치)
2. **「부처님 노래 재물운」 조회순 검색 결과** (남의 채널, 최근 한 달 안)

| 조회 | 1줄 | 제일 큰 줄 | 아래 |
|---|---|---|---|
| 52만 | 노래로 듣는 | **금강경** | 듣고나면 인생이 달라집니다 |

## 2. 남의 채널 — 지금 조회순 위쪽 (최근 한 달)

제목에서 되풀이되는 네 가지입니다.

| 장치 | 실제 제목 |
|---|---|
| **숫자** | 딱 **30분**만 들으세요 · **5분**만 들어라 · **30억** 대운 · **3대**가 먹고살 |
| **놓치면 손해** | **놓치면 후회** · **지나치면 평생 후회** · 안 들으면 **평생 재물운 멀어집니다** |
| **2인칭 지목** | **이 영상 보는 분** 복권운이 찾아옵니다 · **보이면 꼭** |
| **구체 명사** | **복권운** · **로또1등** · **돈벼락** · **귀인** · **조상님** |

썸네일도 같습니다.

```
꽉막힌 돈줄          ← 빨강, 큼
딱 30분만 틀어두면    ← 흰색      (숫자)
3대가 먹고살         ← 초록, 큼  (숫자)
재물 터집니다         ← 노랑, 큼
```

```
보름달 뜨기전        ← 때를 못 박음
지금 딱 틀어두세요
평생 재물복          ← 큰 명사
들어옵니다
```

**네 줄 모두 내용이 있습니다.** 빈 줄이 하나도 없습니다.

## 3. 우리가 안 하고 있는 것

| | 잘 되는 것 | 우리가 쓴 것 |

| 숫자 | 딱 30분만 · 3대가 · 10억 | **없음** |
| 구체 명사 | 복권운 · 금강경 · 귀인 | 돈줄·돈길 (그나마 최근에야) |
| 손해 회피 | 놓치면 후회 | **없음** |
| 증언 | 실화입니다 | **없음** |
| 제일 큰 줄 | 구체 명사 | 「싹 풀립니다」 같은 서술어 |
| 그림 | 금화·지폐가 쏟아지고 웃는 가족 | 잔잔한 수채화 천수관음 (사람 없음) |

## 4. 제안

**(가) 썸네일 문구 틀을 바꿉니다** — 네 줄 모두 내용을 넣고, 숫자와
구체 명사를 씁니다.

```
놓치면 후회합니다        ← 손해 회피
딱 30분만 틀어두면       ← 숫자
3대가 먹고살            ← 숫자 + 구체
재물 터집니다            ← 큰 명사
```

**(나) 제목에 숫자와 「놓치면」을 넣습니다.** A형 틀은 그대로 두되
상황표 자리에 `[딱 30분]` 같은 것을 씁니다.

**(다) 그림 방향 — 그대로 가기로 정해졌습니다 (2026-10-06)**

잘 되는 것들은 금화·지폐가 쏟아지고 웃는 가족 얼굴이 들어가서, 한 장
시험으로 뽑아 볼지 여쭸습니다. 사장님 답은 **「그림도 저정도면
괜찮은거같아」** 였습니다. **지금 화풍 그대로 갑니다.** 다시 여쭙지
않습니다.
