불심명언은 `lovezzang915` 로 **쓸 수는 있지만 소유자가 아닙니다.** 유튜브

브랜드 계정 선택 화면에서 불심명언을 골라도 토큰이 개인 채널로 발급됩니다

소유자 계정을 찾으면 한 번 인증으로 풀립니다. 그 계정으로
`myaccount.google.com/brandaccounts` 를 열었을 때 **불심명언에 「권한 관리」
파란 버튼이 보이면** 그 계정이 소유자입니다. `lovezzang915` 에는 그 버튼이
없습니다.

## 왜 자꾸 막히나 — 원인 세 가지

1. **브라우저 하나에 계정 일곱 개**가 로그인돼 있어, 구글 화면마다 보이는
   채널 목록이 다르게 나옵니다. OAuth 선택 화면과 유튜브 계정 전환 화면이
   서로 다른 목록을 보여준 적도 있습니다
2. **기본 브라우저가 네이버 웨일**이라, 인증 창은 웨일에 뜨는데 제가 정확히
   다룰 수 있는 것은 크롬입니다. 웨일은 좌표를 찍어 누르는 수밖에 없어
   화면이 조금만 바뀌어도 엉뚱한 곳을 누릅니다
3. **브랜드 계정은 소유권과 접근 권한이 다릅니다.** 화면에서 되는 것이
   API 에서 된다는 뜻이 아닙니다

## 다음에 채널을 새로 붙일 때 순서

1. 그 채널이 어느 계정 소유인지 먼저 확인 — `brandaccounts` 에서
   「권한 관리」 버튼이 보이는 계정
2. `도구/채널/<이름>.json` 에 채널 번호·토큰 파일·클라이언트 파일을 적기
3. `python 업로드.py --채널 <이름> --인증만` 으로 토큰 한 번 만들기
4. 이 문서 표에 한 줄 추가

## 새 채널을 붙일 때

1. 그 채널 계정의 크롬 프로필을 확인하고 바탕화면에 `채널) <이름>` 으로
   바로가기를 만든다
2. 그 창에서 인증을 돌린다 (계정이 하나뿐이라 헷갈릴 일이 없다)
3. 토큰이 생기면 그 뒤로는 로그인 없이 API 로 업로드한다

## 불심명언 API 인증 — 여기까지 해봤다 (2026-09-23)

**결론: 안 된다. 다시 시도하지 말고 스튜디오 업로드로 간다.**

계정을 바꿔 가며 인증해 본 결과. 「불심명언」을 골라도 토큰은 그 계정의
다른 채널로 발급된다.

| 인증에 쓴 계정 | 발급된 채널 |
|---|---|
| `lovezzang915` | 웃어봐yo |
| `youinfonews1` | AIC |
| `gmahyun0915` | 황금 주파수 (이건 정상) |

같이 시도했지만 결과가 바뀌지 않은 것들:

- 전용 OAuth 앱(`peerless-aria-471307-p0`) 새로 만들기
- 검증된 황금주파수 앱(`careful-granite-465907-q8`) 쓰기
- 토큰 회수 후 `prompt=consent select_account` 로 새 동의 강제
- 웨일 시크릿 창에서 계정 하나만 두고 인증
- 크롬 프로필별(`--profile-directory`) 창에서 인증
- 앱을 프로덕션으로 게시 → 홈페이지·개인정보처리방침 URL 이 없어 막힘

브랜드 계정 세부정보에서 불심명언에 **「권한 관리」 버튼이 없다.** 알랑가몰랑
같이 실제로 소유한 것에는 있다. 즉 이 PC 에 로그인된 계정 중 소유자가 없다.

### 그래서 불심명언은 이렇게 올린다

1. `python 캡컷모음집만들기.py --채널 불심명언 …` 까지는 평소대로
2. **업로드만 유튜브 스튜디오에서 파일을 올린다** (5분)
3. 제목·설명·챕터·태그는 `_완성/업로드정보.json` 에서 복사해 붙인다
4. 썸네일도 같은 폴더의 `썸네일.jpg`

수익 창출을 켜려면 **광고 적합성 자가진단**을 해야 하는데, 항목 목록
**맨 아래에 「해당 사항 없음」 체크박스**가 있다. 그것만 체크하면
「광고 게재 적합성」으로 통과한다. 위쪽 라디오는 건드리면 안 된다
(하나라도 고르면 광고 제한으로 잡힌다).
