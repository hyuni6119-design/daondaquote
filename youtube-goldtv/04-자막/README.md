# 자막

`.srt` 형식으로 저장합니다. 유튜브 스튜디오 → 자막 → 파일 업로드에서 그대로 올릴 수 있습니다.

## 형식 예시

```
1
00:00:00,000 --> 00:00:03,500
앞유리에 실금 하나 생겼다고

2
00:00:03,500 --> 00:00:07,200
그냥 두시는 분들 많으시죠?
```

## 읽기 좋은 자막 규칙

- 한 줄 **15자 이내**, 최대 두 줄
- 한 자막이 화면에 **최소 1.5초**는 떠 있어야 합니다
- 문장이 길면 의미 단위로 끊습니다
- 쉼표·마침표는 생략해도 됩니다. 줄바꿈이 그 역할을 합니다
