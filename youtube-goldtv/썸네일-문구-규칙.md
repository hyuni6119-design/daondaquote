# 썸네일 문구 규칙

사장님이 불심명언 썸네일을 보고 「너무 구리다」고 하셔서, 유튜브에서
같은 검색어로 실제 잘 되는 영상들을 뽑아 썸네일을 하나하나 들여다보고
정리한 것입니다. 조사일 **2026-09-28**.

**여기서 정하는 것은 문구뿐입니다.** 글꼴·크기·색·자리는 사장님이 캡컷에
잡아 두신 값이고 건드리지 않습니다.

---

## 1. 무엇을 보고 정했나

검색어 `불교노래`·`찬불가`·`불교 트로트`, 20분 이상, 조회수 순.

| 조회 | 채널 | 썸네일에 박힌 글씨 |
|---|---|---|
| 19만 (4주) | 연화스님 달빛트롯 | 귀가 녹습니다 / **트로트 메들리** / 그냥 틀어놓으세요 |
| 5.9만 (2주) | 부처님마음선율 | 오늘 꼭 틀어놓으세요 / **자녀 일이 / 잘 풀립니다** / 틀어만 놓아도 자식 일이 잘 풀립니다 |
| 40만 | 황금 주파수 TV (우리) | 노래로 듣는 / **자녀를 위한 기도** / 듣기만 해도 자녀 인생이 바뀝니다 |
| 34만 | 금빛선율 | 그냥 틀어 놓으세요 / 소원을 이뤄주는 / **천수경** 노래 |
| 31만 | 연꽃소리 | 5시간 반복 불교음악 16곡 + **곡 목록 16줄** |

우리 채널의 40만짜리가 이 목록에 들어 있습니다. **우리도 한 번 해냈던
방식인데 지금 안 하고 있는 것**입니다.

## 2. 지금 우리 불심명언 문구가 진 이유

6편 썸네일입니다.

```
혼자라 느껴질 때
기대어 온 손들이
하나둘 떠오르고
마음이 따뜻해집니다
```

셋이 어긋났습니다.

**첫째, 문장이 끝나지 않습니다.** 「하나둘 떠오르고」는 연결어미로 끊겨
있습니다. 잘 되는 것들은 예외 없이 `~습니다`·`~하세요`로 딱 닫습니다.
읽다 만 느낌이면 손가락이 그냥 지나갑니다.

**둘째, 이득이 없습니다.** 「마음이 따뜻해집니다」는 분위기이지 약속이
아닙니다. 경쟁작은 전부 **누구의 무엇이 좋아지는지**를 적습니다 — 자녀
일이 풀린다, 소원이 이뤄진다, 인생이 바뀐다.

**셋째, 검색어가 한 낱말도 없습니다.** 천수경·자녀·부모·소원·기도 같은
말이 글씨에 박혀 있어야 같은 칸의 영상으로 읽힙니다.

한마디로 **가사를 그대로 옮겨 적은 것**이 문제입니다. 가사는 시라서
그 자체로는 무슨 영상인지 알려 주지 않습니다.

## 3. 네 줄에 무엇을 넣는가

두 채널 모두 네 줄 폼입니다. 줄마다 맡은 일이 다릅니다.

| 줄 | 맡은 일 | 글자 수 |
|---|---|---|
| 1 | **언제·누가** — 상황을 좁히고 행동을 시킨다 | 7~10자 |
| 2 | **약속의 앞부분** | 4~7자 |
| 3 | **약속의 뒷부분 — 반드시 서술어로 닫는다** | 4~7자 |
| 4 | **약속을 한 번 더, 조건을 붙여서** | 10~14자 |

2줄과 3줄은 **합치면 한 문장**이 되어야 합니다. 이게 제일 중요합니다.

```
오늘 꼭 틀어놓으세요      ← 1줄
자녀 일이                 ← 2줄
잘 풀립니다               ← 3줄   (2+3 = "자녀 일이 잘 풀립니다")
틀어만 놓아도 [마음이 놓입니다]   ← 4줄, 대괄호가 강조색
```

## 4. 부품 사전

**1줄 (상황·행동)**

```
오늘 꼭 틀어놓으세요 · 그냥 틀어놓으세요 · 자기 전에 틀어요
비 오는 날 들어요 · 새벽에 깨면 트세요 · 일하면서 틀어두세요
부모님께 들려드리세요 · 마음이 무거운 날
```

**2·3줄 (약속) — 앞에 대상, 뒤에 서술어**

| 대상 | 서술어 |
|---|---|
| 자녀 일이 · 자식 앞길이 · 부모님 마음이 | 잘 풀립니다 · 열립니다 |
| 막혔던 일이 · 얽힌 일이 | 술술 풀립니다 · 풀려 갑니다 |
| 묵은 근심이 · 쌓인 화가 | 씻겨 나갑니다 · 가라앉습니다 |
| 잠 못 들던 밤이 · 무겁던 아침이 | 편해집니다 · 가벼워집니다 |
| 끊겼던 인연이 · 서먹하던 사이가 | 이어집니다 · 풀립니다 |
| 소원이 · 바라던 일이 | 이뤄집니다 · 닿습니다 |

**4줄 (되풀이) — 「조건 + 결과」**

```
틀어만 놓아도 [~합니다]   ·  듣기만 해도 [~합니다]
한 번만 들어도 [~합니다]  ·  오늘부터 [~합니다]
```

**경전 이름을 넣을 자리가 있으면 넣습니다.** 천수경·반야심경·금강경·
법구경은 그 자체가 검색어입니다. 2줄을 「소원을 이뤄주는」, 3줄을
「천수경 노래」로 쓰는 식입니다.

## 5. 하지 않는 것

- **가사를 옮겨 적지 않습니다.** 문구는 따로 씁니다
- 연결어미(`~고`, `~며`, `~처럼`, `~때`)로 3줄을 끝내지 않습니다
- 한 줄이 8자를 넘지 않습니다. 넘으면 글자가 작아져 멀리서 안 읽힙니다
- 「마음이 편안해집니다」처럼 분위기만 말하고 마는 문구는 쓰지 않습니다.
  누구의 무엇이 좋아지는지 적습니다
- 기복이 지나친 단정(「반드시」·「무조건」·「100%」)은 피합니다.
  유튜브가 싫어하고, 사장님 채널의 결에도 맞지 않습니다

## 6. 따로 남겨 두는 것 — 배경 그림 대비

문구와 별개로 눈에 걸린 것이 있습니다. 불심명언 배경은 **금색 천수관음상
+ 베이지 배경**이라 글자와 그림의 색이 서로 비슷합니다. 잘 되는 것들은
보라 밤하늘·눈밭·노을처럼 **대비가 셉니다.**

그림 방향은 사장님이 정하신 것이라(`goldtv-thumbnail-art-style`) 제가
멋대로 바꾸지 않습니다. 배경만 어둡거나 푸른 쪽으로 한 번 뽑아 나란히
보시겠다면 말씀해 주세요.
