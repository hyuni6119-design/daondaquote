# 유튜브 제목·설명 규칙

사장님이 정해 주신 작성 지침과, 잘 나가는 불교 채널 제목들을 뜯어보고 만든
틀입니다. `도구/업로드정보만들기.py` 가 이 틀대로 `업로드정보.json` 을 만듭니다.

---

## 기본 지침 (사장님 지시 원문)

노래 가사를 기반으로 유튜브 업로드용 제목과 설명을 작성합니다.

- 제목은 **클릭률을 높일 수 있도록 감성적이고 자극적**이며, 유튜브
  알고리즘에 잘 노출될 수 있는 **키워드**를 포함합니다.
- 설명에는 **곡의 의미와 불교적 메시지를 간결하게 요약**하고, 시청자의
  관심을 끌 수 있는 문장과 **해시태그**를 포함합니다.
- 특히 **「부자 되는 느낌」·「복을 부르는」·「마음이 편해지는」** 키워드를
  자연스럽게 녹여서 작성합니다.
- **썸네일 문구는 사장님이 따로 요청할 때만** 만듭니다.
- **라이브(틀어놓기용 롱폼)** 영상은 1단계 가사와 관계없이
  「부자되는 노래」·「부처님 말씀」·「복을 부르는 음악」 같은 키워드로
  **제목과 설명을 각각 2개 이상** 추천하고, 자극적이고 클릭을 유도하는
  **썸네일 문구를 3줄 형식으로 3개씩** 함께 제시합니다.

> `00-채널정보.md` 에는 자극적 문구와 기복 표현을 피하라고 적혀 있습니다.
> 이 지침이 그보다 우선합니다. 사장님이 정하신 방향입니다.

## 1. 제목 — 잘 나가는 채널 제목 분석

사장님이 주신 실제 인기 영상 제목들을 뜯어보니 형태가 **두 가지**입니다.
둘 다 유튜브 제목 한도 100자 안에서 **84~93자**를 꽉 채워 씁니다.
제목 뒤쪽에 **검색 키워드를 가운뎃점(·)으로 이어 붙여 태그처럼 심는 것**이
이 바닥의 공통 문법입니다.

### A형 — 「지금! 꼭! 틀어놓으세요」 형 (1시간 40분대 롱폼)

```
🚨[상황표] 지금! 꼭! 틀어놓으세요🙏 {주어} "{나쁜 것}" {씻는 말} {좋은 것 앞말} "{좋은 것}" {쏟아지는 말}{🍀|✨} | 부처님 노래 | {태그}·{태그}·{태그}·찬불가·불교노래
```

관찰된 규칙 다섯 가지입니다.

1. **큰따옴표로 핵심어 두 개를 감쌉니다.** 하나는 없앨 것, 하나는 들어올 것.
   예) `"고생" 끝나고 "황금빛 대운" 쏟아집니다`
2. **「나쁜 것이 사라지고 → 좋은 것이 들어온다」 2단 구조**를 반드시 지킵니다.
3. **이모지는 세 자리에 고정**입니다. 맨 앞 🚨 / 행동 유도 뒤 🙏 / 문장 끝 🍀 또는 ✨
4. **`| 부처님 노래 |`** 는 통째로 고정 구분자입니다.
5. 뒤 태그는 3~5개를 가운뎃점으로 잇고, **마지막 두 개는 늘 `찬불가·불교노래`** 입니다.

부품 사전

| 자리 | 쓸 수 있는 말 |
|---|---|
| 상황표(선택) | `[9월 22일]` `[초하루기도]` `[자녀기도]` `[가족기도]` `[소원기도]` |
| 주어 | 우리 집안 · 내 자식 · 온 가족 · 오늘부터 · 이번 달 내내 |
| 나쁜 것 | 액운 · 고생 · 막힌 운 · 막힌 일 · 나쁜 기운 · 근심 · 업장 · 우환 |
| 씻는 말 | 씻겨가고 · 끊어지고 · 끝나고 · 뚫리고 · 사라지고 · 풀리고 |
| 좋은 것 | 큰 돈복 · 황금빛 대운 · 만사형통 · 기쁜 소식 · 태평성대 · 탄탄대로 · 운수대통 · 부귀영화 · 만사평안 |
| 쏟아지는 말 | 콸콸 쏟아집니다 · 쏟아집니다 · 활짝 열립니다 · 다 이루어집니다 · 누립니다 · 대박 터집니다 · 줄줄이 들려옵니다 |
| 태그 | 재물운 금전운 돈복 횡재수 만사형통 만사대길 운수대통 소원성취 액운소멸 업장소멸 우환소멸 무병장수 가내평안 가족평안 자녀성공 취업발원 마음정화 |

### B형 — 「기도노래」 형 (40분대)

```
{주제어} 기도노래🕯️{효과 서술} 불교노래✨ 소원성취 불교음악🙏만사형통 기도 #해시 #해시 #해시
```

- 주제어: 관음보살 · 업장소멸 복덕 · 황금대운 · 길운도래 · 만복도래 · 가족평안
- 효과 서술: 「막힌 복길이 열리고 바라던 좋은 소식 이어지는」처럼 **관형절로** 씁니다
- 꼬리 `소원성취 불교음악🙏만사형통 기도` 는 거의 고정입니다
- 해시태그 3개로 끝냅니다: `#천수경 #찬불가 #금전운`

### 어느 형을 쓸까

| 영상 길이 | 형 |
|---|---|
| 1시간 이상 모음집 | **A형** |
| 40분 안팎 | **B형** |

### 주의

- 날짜를 넣으면 그날만 쓰는 제목이 됩니다. **다시 쓸 제목이면 날짜를 빼고**
  `[가족기도]` 같은 상황표만 씁니다
- 같은 「좋은 것」을 이틀 연속 쓰지 않습니다 (돈복 → 대운 → 기쁜 소식 …)
- 100자를 넘기면 뒤 태그부터 하나씩 뺍니다

## 2. 설명

순서를 고정합니다.

```
1) 후킹 문단 — 관심을 끄는 두세 줄. 부자·복·마음 키워드를 녹입니다
2) 곡의 의미 — 이 영상에 담긴 불교적 메시지를 간결하게
3) 수록곡   — 타임스탬프. 0:00 으로 시작해야 유튜브가 챕터로 인식합니다
4) 출처 경전 — 곡마다 경전 이름과 인용 원문
5) 저작 고지 — 가사는 새로 쓴 창작물이라는 문장
6) 채널 소개 — 한 줄
7) 해시태그  — 8~12개
```

### 타임스탬프 규칙

- 반드시 **0:00 부터** 시작합니다
- 한 시간이 넘으면 `1:04:40` 처럼 시:분:초로 씁니다
- 같은 제목의 곡이 여러 번 나오면 뒤에 `(2)`, `(3)` 을 붙입니다
