#### 1차 — 클라우드플레어 차단 (403)

```
[실패] 서버가 403 로 답했습니다.
{"type":"https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1010/","title":"Error 1010: Access denied","status":403,"detail":"The site owner has blocked access based on your browser's signature.","instance":"a3be1ba02a09d1e5","error_code":1010,"error_name":"browser_signature_banned","error_category":"access_denied","ray_id":"a3be1ba02a09d1e5","timestamp":"2026-09-16T07:20:19Z","zone":"api.sunoapi.org","cloudflare_error":true,"retryable":false,"owner_action_required":true,"what_you_should_do":"**Do not retry.** Your user-agent has been banned by the site owner.","footer":"This error was generated by Cloudflare on behalf of the website owner."}
```

원인은 파이썬 `urllib` 이 기본으로 보내는 `Python-urllib/3.13` User-Agent 입니다.
클라우드플레어가 이걸 봇으로 보고 막습니다. 수노 API 형식 문제가 아니라 접속 자체가
막힌 것이라, `노래만들기.py` 의 `보내기()` 헤더에 평범한 브라우저 User-Agent 를
한 줄 넣었습니다.

```python
"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
              "AppleWebKit/537.36 (KHTML, like Gecko) "
              "Chrome/140.0.0.0 Safari/537.36",
```

이 수정으로 403 은 사라졌습니다. **이 한 줄은 계속 필요합니다.**

#### 2차 — callBackUrl 누락 (400)

```
[실패] 작업 번호를 못 받았습니다. 응답은 아래와 같습니다.
{
  "code": 400,
  "msg": "Please enter callBackUrl.",
  "data": null
}
```

클라우드플레어를 통과해 진짜 수노 API 가 답한 첫 응답입니다.
`api.sunoapi.org` 는 `callBackUrl` 을 필수로 받습니다.
스크립트에 이미 `곡.get("콜백주소")` 를 읽는 자리가 있어서
`곡정보.json` 에 아래를 넣었습니다.

```json
"콜백주소": "https://example.com/callback",
```

결과는 `record-info` 로 직접 조회해 받으므로 콜백을 실제로 수신할 필요는 없습니다.
형식 검사만 통과하면 됩니다.

> 곡정보-예시.json 에도 `콜백주소` 를 넣어두는 게 좋겠습니다.
> 다음 곡부터 같은 400 을 또 만나게 됩니다.

#### 3차 — 크레딧 부족 (429) ← 지금 여기서 멈춤

```
[실패] 작업 번호를 못 받았습니다. 응답은 아래와 같습니다.
{
  "code": 429,
  "msg": "The current credits are insufficient. Please top up.",
  "data": null
}
```

주소·형식·인증이 전부 맞아서 계정 잔액까지 도달했습니다.
**스크립트 문제가 아닙니다.** sunoapi.org 계정에 크레딧을 충전하면
그대로 다시 돌리면 됩니다.

**4단계** — `영상\` 폴더가 여전히 비어 있어 영상 만들기는 시작하지 않았습니다.

```js
const r = document.createRange(); r.selectNodeContents(el);
const s = getSelection(); s.removeAllRanges(); s.addRange(r);
document.execCommand('insertText', false, '넣을 글');
```

저장 단추는 `#save` 인데 보통 클릭이 안 먹어서 **pointer 이벤트를
순서대로** 보내야 합니다 (수노에서 쓰던 방법과 같습니다).

```js
const b = document.querySelector('#save');
const t = b.querySelector('button') || b;
['pointerover','pointerdown','mousedown','pointerup','mouseup','click']
  .forEach(n => t.dispatchEvent(new (n.startsWith('pointer')?PointerEvent:MouseEvent)(
    n, {bubbles:true, cancelable:true, composed:true})));
```
