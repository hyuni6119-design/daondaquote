# [001] 비우니 오히려 채워지더라 — 가사

- **출처 경전**: 반야심경 (마하반야바라밀다심경)
- **핵심 구절(원문)**: 색즉시공 공즉시색 (色卽是空 空卽是色)
- **구절 뜻**: 형체 있는 것이 곧 비어 있고, 비어 있음이 곧 형체다
- **목표 길이**: 롱폼 12분 (노래 약 5분 × 2회 + 낭송 인트로 + 간주)
- **곡 분위기**: 느린 3박 또는 6/8박 / 대금·가야금 + 잔잔한 피아노 / 낮고 편안한 중년 음색

---

## 가사

### 인트로 — 낭송 (약 40초)

```
색즉시공 공즉시색

있는 것이 곧 비어 있고
비어 있음이 곧 있는 것이라

부처님은 그리 이르셨습니다
```

### 1절

```
손에 쥔 걸 세어보니
남은 게 별로 없더라
집 한 채 이름 석 자
그마저도 빌린 거였네

꽉 쥐면 쥘수록
손바닥만 아프더라
놓으라는 그 말이 야속했는데
놓고 보니 알겠네
```

### 후렴

```
비우니 채워지더라
버리니 남더라
색즉시공 공즉시색
있고 없고가 한자리였네

내려놓게 내려놓게
그 손 이제 펴게
쥐고 있던 것들 다
처음부터 내 것 아니었네
```

### 2절

```
자식들 다 키워놓고
빈 방에 앉아보니
그 애들도 내 것이 아니라
잠시 맡아 기른 것이었네

서운했던 말 한마디
가슴에 박아 두었는데
꺼내보니 아무것도 없고
내가 쥐고 있었을 뿐
```

### 후렴 (반복)

```
비우니 채워지더라
버리니 남더라
색즉시공 공즉시색
있고 없고가 한자리였네

내려놓게 내려놓게
그 손 이제 펴게
쥐고 있던 것들 다
처음부터 내 것 아니었네
```

### 브릿지

```
꽃이 피면 진다고
서러워하지 않듯이
채워지면 비는 것도
그저 그런 일이더라
```

### 마무리

```
빈 마루에 바람 한 줄
풍경이 울고 지나가네

비어서 소리가 나는 거였네
비어서 울리는 거였네

색즉시공 공즉시색
```

## 가사 해설 (제작 참고용)

| 구간 | 경전과의 연결 |
|---|---|
| 1절 | 오온개공(五蘊皆空) — 내 것이라 여긴 것이 실은 조건으로 잠시 모인 것 |
| 후렴 | 색즉시공 공즉시색 — 있음과 없음이 둘이 아님 |
| 2절 | 무아(無我) — 자식도 감정도 '소유'가 아님 |
| 브릿지 | 제행무상(諸行無常) — 변하는 것이 잘못이 아니라 본래 그러함 |
| 마무리 | **범종과 풍경은 속이 비어 있어서 울린다.** 비움이 결핍이 아니라 울림의 조건이라는 마무리 |

## 영상 구성 (12분)

| 시간 | 구간 | 화면 |
|---|---|---|
| 0:00~0:40 | 낭송 인트로 | 새벽 산사, 안개 낀 일주문, 서서히 밝아오는 하늘 |
| 0:40~1:10 | 전주 | 흔들리는 풍경(風磬) 클로즈업 |
| 1:10~2:10 | 1절 | 주름진 손, 열쇠 꾸러미, 오래된 문패 |
| 2:10~3:00 | 후렴 | 펴지는 손바닥, 비어가는 찻잔, 바람에 흩어지는 것 |
| 3:00~4:00 | 2절 | 빈 방, 개어놓은 이불, 벽에 걸린 가족사진 |
| 4:00~4:50 | 후렴 | 산사 마당, 비질 자국, 저녁 햇살 |
| 4:50~5:30 | 브릿지 | 지는 꽃, 떨어지는 잎, 다시 피는 싹 |
