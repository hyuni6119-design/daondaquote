지금 작업 상태를 클라우드 Claude가 볼 수 있게 저장소에 올려줘.

1. `git pull origin claude/fervent-mendel-124aee`
2. 아래를 확인한다.
   - 파이썬 / ffmpeg 설치 여부 (`python --version`, `ffmpeg -version`)
   - `youtube-goldtv/도구/` 안에 `api키.json`, `client_secret.json` 이 있는지 (**있는지 여부만**, 내용은 열지 말 것)
   - 작업 폴더에 어떤 파일이 있는지 (`노래.mp3`, `영상\`, `완성.mp4`, `썸네일.png`)
   - 방금 실행한 명령에서 난 오류가 있으면 그 원문
3. `youtube-goldtv/작업기록.md` 맨 위에 위 내용을 날짜와 함께 추가한다.
4. 커밋하고 푸시한다.
5. 사용자에게 "클라우드 대화에서 '작업기록 확인해줘' 라고 하시면 됩니다" 라고 알려준다.

**키 값은 절대 기록하지 않는다. 파일이 있는지 없는지만 적는다.**
