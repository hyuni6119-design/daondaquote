클라우드 Claude가 저장소에 올려둔 지시사항을 받아 실행해줘.

## 순서

1. **최신 내용 받기**
   ```
   git pull origin claude/fervent-mendel-124aee
   ```
   충돌이 나면 멈추고 사용자에게 알려줘.

2. **지시사항 읽기**
   `youtube-goldtv/지시사항.md` 를 읽는다.

3. **실행하기**
   그 파일의 "지금 할 일" 목록을 **위에서부터 순서대로** 실행한다.
   - `[ ]` 는 아직 안 한 것, `[x]` 는 이미 끝난 것이다. 끝난 것은 건너뛴다.
   - 도구 스크립트는 `youtube-goldtv/도구/` 안에 있다. 사용법은 같은 폴더의 `사용법.md` 참고.
   - API 키나 구글 인증 파일이 없어서 막히면, 그 단계를 건너뛰고 사용자에게 무엇이 필요한지 알려준다.
   - 파일을 지우거나 덮어쓰기 전에는 반드시 먼저 확인한다.

4. **결과 기록하기**
   `youtube-goldtv/작업기록.md` 맨 위에 이번 실행 결과를 추가한다. 형식:
   ```
   ## YYYY-MM-DD HH:MM (로컬 실행)

   ### 한 일
   - 무엇을 실행했고 결과가 어땠는지

   ### 만들어진 파일
   - 경로와 크기

   ### 막힌 것
   - 오류 메시지 원문을 그대로 붙여넣기 (API 키 값은 절대 쓰지 말 것)

   ### 사용자가 해야 할 일
   - 남은 것
   ```

5. **올리기**
   ```
   git add -A
   git commit -m "로컬 작업 결과 기록"
   git push origin claude/fervent-mendel-124aee
   ```
   **주의**: `api키.json`, `client_secret.json`, `인증토큰.json`, mp3, mp4 파일은
   절대 커밋하지 않는다. `.gitignore` 로 막혀 있으니 확인만 한다.

6. 마지막으로 사용자에게 한 일과 남은 일을 짧게 보고한다.

## 중요

- 오류 메시지는 **요약하지 말고 원문 그대로** `작업기록.md` 에 남겨라.
  클라우드 쪽 Claude가 그걸 보고 스크립트를 고친다.
- 키 값은 어떤 경우에도 기록하거나 출력하지 않는다.
