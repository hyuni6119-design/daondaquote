다온다 견적서 - 윈도우 탐색기로 공유폴더 열기 (설치 방법)
============================================================

이 설치는 PC 한 대당 딱 한 번만 하면 됩니다. 관리자 권한 필요 없습니다.


[1단계] 폴더 만들고 파일 넣기
------------------------------------------------------------
1. C 드라이브에 daonda 라는 폴더를 만듭니다.
   → 최종 모습:  C:\daonda

2. 같이 받은 daonda-open.vbs 파일을 그 안에 넣습니다.
   → 최종 모습:  C:\daonda\daonda-open.vbs

   ※ 폴더 이름과 위치가 정확해야 합니다. 다르면 동작하지 않습니다.


[2단계] 등록 파일 실행
------------------------------------------------------------
1. "1-탐색기열기-설치.reg" 파일을 더블클릭합니다.
2. "정말 계속하시겠습니까?" 경고가 뜨면 [예]를 누릅니다.
3. "성공적으로 추가되었습니다" 가 뜨면 끝입니다.


[3단계] 견적서 앱에서 켜기
------------------------------------------------------------
1. 견적서 앱을 엽니다.
2. [보험사별 표준자료 관리] → [공유폴더 설정] 을 엽니다.
3. 맨 위 "윈도우 탐색기 창으로 열기" 체크박스를 켭니다.
4. 보험사별로 폴더 경로를 붙여넣습니다.

   경로 복사하는 법:
   - 파일 탐색기에서 그 폴더를 엽니다
   - 주소창을 클릭하거나 Ctrl+L 을 누릅니다
   - 주소가 글자로 바뀌면 Ctrl+C 로 복사합니다
     (예: Z:\다온다자동차유리\2026년\가맹점)


[4단계] 사용
------------------------------------------------------------
견적서 화면에서 [공유폴더 열기] 버튼을 누르면
윈도우 탐색기 창이 해당 폴더에서 바로 열립니다.

처음 한 번은 크롬이 "daonda을(를) 여시겠습니까?" 라고 묻습니다.
"항상 허용" 에 체크하고 [열기] 를 누르면 다음부터 안 묻습니다.


[문제가 있을 때]
------------------------------------------------------------
* 버튼을 눌러도 아무 반응이 없다
  → 1단계 파일 위치(C:\daonda\daonda-open.vbs)를 다시 확인하세요.
  → 그래도 안 되면 앱의 "윈도우 탐색기 창으로 열기" 체크를 끄세요.
     브라우저 탭으로 폴더 내용을 보는 방식으로 돌아갑니다.

* 잘못 설치해서 되돌리고 싶다
  → "삭제하려면.reg" 를 더블클릭하면 등록이 지워집니다.

* 회사 보안 프로그램이 막는다
  → 이 방식은 쓸 수 없습니다. 알려주시면 다른 방법을 찾아 드립니다.
