# 영상 관리 사이트

황금주파수 TV · 불심명언 편마다 **썸네일, 제목, 진행상황, 공개 날짜, 조회수**를
한눈에 보고 관리하는 사이트입니다. 라이브 사이트와 **완전히 따로** 돕니다.

```
[사장님 PC]  Claude가 수노 → 캡컷 → 업로드 (지금처럼 원격으로)
     │  끝날 때마다  python 보고.py ...  로 사이트에 보고
     ▼
[헤츠너 서버]  영상 관리 사이트 (24시간)
     - 카드 / 달력으로 편 보기, 상태별로 걸러 보기
     - 썸네일·제목·설명 고치기 → "반영 시키기" → PC가 실제로 반영
     - "이 편 진행", "이어서 진행", "잠깐 멈춤" 버튼 → PC가 받아서 작업
     - PC가 지금 무엇을 하는지, 막힌 곳은 어디인지
     - 조회수 (선택)
```

처음 켜면 **기존 「작업 대시보드」의 23편 기록을 자동으로 옮겨 옵니다** (`seed/`).

## 1. 서버에 설치 (Live-manager 대화에 맡기면 됩니다)

라이브 사이트와 섞이지 않게 **다른 폴더 · 다른 포트 · 다른 주소**를 씁니다.

```bash
# 서버에서
git clone -b claude/lucid-mccarthy-4kxru6 https://github.com/hyuni6119-design/daondaquote.git /opt/video-manager-src
cp -r /opt/video-manager-src/video-manager /opt/video-manager
cd /opt/video-manager
cp .env.example .env
#  .env 를 열어 채웁니다
#    ADMIN_PASSWORD = 사이트 비밀번호
#    API_TOKEN      = openssl rand -hex 24 로 만든 값
#    SECRET_KEY     = openssl rand -hex 32 로 만든 값
docker compose up -d --build
curl -s localhost:8090/login | head -3     # 열리는지 확인
```

그다음 바깥 주소를 붙입니다. sslip.io 는 앞에 아무 이름이나 붙여도 같은 서버로
옵니다. 그래서 **`video.168-119-152-95.sslip.io`** 를 이 사이트(서버의 `127.0.0.1:8090`)로
보내도록 지금 쓰고 있는 리버스 프록시(Caddy·Nginx·Traefik 등)에 한 줄 추가하고,
HTTPS 인증서를 받습니다. 라이브 사이트 설정은 건드리지 않습니다.

Caddy 예시:
```
video.168-119-152-95.sslip.io {
    reverse_proxy 127.0.0.1:8090
}
```

데이터는 `/opt/video-manager/data/` 에 있습니다 (DB 파일 하나 + 썸네일 그림).
백업은 이 폴더만 복사하면 됩니다.

### 조회수도 보고 싶으면 (선택)

구글 클라우드 콘솔 → API 및 서비스 → 사용자 인증 정보 → **API 키** 만들기 →
`.env` 의 `YT_API_KEY` 에 넣고 `docker compose up -d`. 사이트 아래에
「조회수 새로고침」 버튼이 생깁니다. (공개된 영상만 숫자가 나옵니다)

## 2. PC 쪽 준비 (PC의 Claude에게 맡기면 됩니다)

1. `pc/보고.py` 를 `youtube-goldtv/도구/` 에 복사합니다.
2. 같은 폴더에 `관리사이트.json` 을 만듭니다 (`pc/관리사이트-예시.json` 참고).
   토큰은 서버 `.env` 의 `API_TOKEN` 값입니다.
3. `youtube-goldtv/도구/.gitignore` 에 `관리사이트.json` 을 추가합니다. **커밋 금지.**
4. 확인: `python 보고.py 할일` → "시켜 둔 일이 없습니다." 가 나오면 연결 성공.

### 작업할 때 보고하는 법

| 언제 | 명령 |
|---|---|
| 일을 시작할 때 | `python 보고.py 지금 --상태 일함 --하는일 "불심명언 21편 영상 만드는 중" --다음 "썸네일"` |
| 단계 하나 끝날 때 | `python 보고.py 단계 --채널 불심명언 --편 21 --단계 "영상 만들기" --상태 완료` |
| 막혔을 때 | `python 보고.py 단계 --채널 불심명언 --편 21 --단계 다운로드 --상태 막힘 --메모 "수노 로그인 풀림"` |
| 업로드 끝나면 | `python 보고.py 업로드정보 --채널 불심명언 --편 21 --폴더 "D:\불심명언\_완성21"` |
| 일을 마칠 때 | `python 보고.py 지금 --상태 쉼 --마지막 "21편 예약 완료" --다음 "22편 가사"` |

`업로드정보` 는 그 폴더의 `업로드정보.json`(제목·설명·태그·예약시간),
`썸네일.json`(문구), `썸네일.jpg/png`, `업로드결과.txt`(영상 주소),
`수록곡.json`(길이·곡 수)을 한 번에 읽어 올립니다.

단계 이름: 가사 만들기 · 가사 검토 · 수노 노래 만들기 · 다운로드 ·
썸네일 이미지 만들기 · 썸네일 문구 만들기 · 영상 이미지 만들기 · 영상 만들기 · 업로드 예약

### 검토 대기 → 승인 (잘못 만든 영상이 공개되지 않게)

업로드할 때 **예약 공개로 바로 올리지 않고**, 먼저 **일부 공개**(privacyStatus=unlisted, publishAt 없이)로 올립니다.
일부 공개라서 사이트 안에서 바로 재생해 볼 수 있고, 주소를 모르는 사람에게는 안 보입니다.

```bash
# 1) 일부 공개로 올린 뒤
python 보고.py 검토요청 --채널 불심명언 --편 21 --주소 "https://youtu.be/xxxxxxxxxxx"
```

사이트에 「검토대기」로 뜨고, 사장님이 ▶ 스튜디오에서 미리보기로 확인한 뒤
**✅ 승인** 또는 **🔁 다시 만들기**를 누릅니다. 그러면 `할일`에 들어옵니다.

| 종류 | PC가 할 일 |
|---|---|
| 승인 | 그 영상(payload.video_id)을 공개 날짜(payload.date)의 예약 시각으로 **예약 공개**로 바꾼다 (일부 공개 → privacyStatus=private + publishAt · 유튜브는 예약 공개를 비공개 상태에서만 받음). 끝나면 `처리 --상태 완료` |
| 다시만들기 | payload.note(이유)를 보고 그 편을 다시 만든 뒤, 예전 영상(payload.video_id)은 유튜브에서 **삭제**하고(videos.delete), 새 영상을 다시 일부 공개로 올리고 `검토요청` |

### 사이트에서 시킨 일 받기

```bash
python 보고.py 할일                                  # 기다리는 일 목록
python 보고.py 처리 --번호 3 --상태 작업중
python 보고.py 처리 --번호 3 --상태 완료 --메모 "제목·썸네일 반영함"
```

| 종류 | 뜻 |
|---|---|
| 진행 | 그 편을 처음부터(또는 멈춘 곳부터) 끝까지 만든다 |
| 글고침 | 내용(payload)의 제목·설명·썸네일 문구를 유튜브와 썸네일에 실제로 반영한다 |
| 이어서 | `작업기록.md` 끝을 보고 하던 일을 이어서 한다 |
| 멈춤 | 하던 일을 멈추고 `지금 --상태 쉼` 으로 보고한다 |

## 3. 파일 구성

```
video-manager/
├── app/
│   ├── main.py        서버 (주소마다 하는 일)
│   ├── db.py          저장 (SQLite 파일 하나)
│   ├── config.py      채널·단계·비밀번호 설정
│   └── static/        화면 (index.html, app.js, style.css, login.html)
├── pc/보고.py          PC의 Claude가 쓰는 보고 도구 (설치할 것 없음)
├── seed/              기존 작업 대시보드에서 옮겨 온 23편
├── Dockerfile, docker-compose.yml, .env.example
```

## 보안

- 사이트는 비밀번호로 잠겨 있고, 10분에 10번 넘게 틀리면 잠시 막힙니다.
- PC는 비밀번호 대신 `API_TOKEN` 으로 들어옵니다. **토큰을 채팅창에 붙여넣지 마세요.**
- `.env`, `data/`, `관리사이트.json` 은 커밋하지 않습니다.
