만드는 방식은 `youtube-goldtv/`(황금주파수 TV)와 **똑같고**, 채널 이름과
썸네일만 다릅니다. 그래서 **도구는 한 벌만 둡니다.**

| 유튜브 채널 | `UCler8uaRkitoZs-BRpvouIw` | `UCzu7geg1OrcCpIlhdEpjINw` |
| 인증 토큰 | `도구/인증토큰.json` | `도구/인증토큰-불심명언.json` |
| 캡컷 본 영상 | 「황주영상-복사」 | 「불심명언 노래-복사」 |
| 캡컷 본 썸네일 | 「황주썸넬」 | 「불심명언 노래 썸넬」 |

## 도구는 어디에 있나

도구는 `youtube-goldtv/도구/` 한 곳에만 있습니다. 두 벌로 복사해 두면
한쪽만 고치는 일이 반드시 생기기 때문입니다. 채널마다 다른 값은
`youtube-goldtv/도구/채널/불심명언.json` 에 적혀 있고, 스크립트에
`--채널 불심명언` 을 붙이면 그 설정으로 돕니다.

```bash
python 업로드.py --채널 불심명언
python 업로드정보만들기.py --채널 불심명언 --프로젝트 0923불심 --저장 "D:\불심명언\_완성"
```

`--채널` 을 빼면 황금주파수로 돕니다. 지금까지 쓰던 명령이 그대로
돌아가야 하기 때문입니다.

## 폴더 구성

| 폴더 | 들어가는 것 |
|---|---|
| `00-채널정보.md` | 채널 주제, 타깃 시청자, 말투 |
| `01-기획/` | 영상별 기획안 |
| `02-가사/` | 곡별 수노 프롬프트(가사) |
| `03-업로드/` | 제목, 설명란, 해시태그, 썸네일 문구 |
| `04-자막/` | 자막 파일 (.srt) |
| `05-리서치/` | 트렌드 조사, 경쟁 채널 분석 |

파일 이름은 황금주파수와 같은 규칙입니다. 영상 하나당 같은 번호를 씁니다.

```
02-가사/001-천개의-손.md
03-업로드/001-천개의-손.md
```

번호는 채널마다 따로 셉니다. 황금주파수의 013번과 불심명언의 013번은
다른 곡입니다.

```
D:\불심명언\
  _오늘이미지\   그날 만든 썸네일용·재생화면용 그림
  _배경영상\     재생화면에 쓰는 배경 영상 (freepik 5개)
  _완성\         완성.mp4 · 업로드정보.json · 썸네일.jpg · 업로드결과.txt
  _보관\         지난 작업물
  <곡제목>\      곡마다 한 폴더
```

시스템 드라이브(C)를 채우지 않으려고 음원·영상은 모두 D에 둡니다.

## 가사는 날마다 새로 씁니다

유튜브가 중복 콘텐츠를 싫어하므로 전날 쓴 경전 구절을 다시 쓰지 않습니다.
**황금주파수에서 쓴 구절도 피합니다.** 두 채널이 같은 구절로 같은 날
올라가면 서로를 갉아먹습니다. `youtube-goldtv/유명-경전구절-모음.md` 의
목록을 두 채널이 나눠 씁니다.
